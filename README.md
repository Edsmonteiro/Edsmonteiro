## 🏆 Projetos principais

### 🚘 Kineo — Gestão de Frotas

Plataforma de gestão de frotas e locações, reunindo **veículos, manutenções, despesas, contratos, cobranças e indicadores gerenciais**. O trabalho envolve regras operacionais e financeiras, organização de dados e apoio à tomada de decisão.

**Tecnologias e conceitos:** Python, SQL, Pandas, SQLAlchemy, PostgreSQL, dashboards e processos de negócio. A evolução da plataforma também contempla uma arquitetura web moderna, desenvolvida em repositório privado.

🔗 [Ver repositório público do Kineo](https://github.com/Edsmonteiro/kineo-gestao-frotas)

### 🧾 Multxz — Gestão de Contratos e Operações

Sistema voltado à rotina de locação de veículos, com módulos de **contratos, cobranças, despesas, multas e notificações**. O desenvolvimento inclui regras de negócio, persistência de dados, testes e preparação para integrações com serviços externos.

**Tecnologias e conceitos:** Next.js, TypeScript, FastAPI, Python e PostgreSQL.

🔒 **Projeto em desenvolvimento privado.** A descrição é geral; código e informações dos clientes não são públicos.

### 🛍️ Digital Store — Aplicação React

Projeto de front-end com **catálogo, filtros, página de produto e interface responsiva**, acompanhado de testes e publicação online. É uma entrega pública que demonstra organização, implementação e validação de interface.

**Tecnologias:** React, JavaScript, Vite, CSS e Playwright.

🔗 [Ver código](https://github.com/Edsmonteiro/digital-store-frontend) · [Acessar aplicação](https://digital-store-frontend-iota.vercel.app)
